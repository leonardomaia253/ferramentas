# MInvest Tools

Free financial decision tools and cited exploratory market research for Claude Code and Codex.

## Claude Code

```sh
claude plugin marketplace add leonardomaia253/ferramentas
claude plugin install minvest-ferramentas-gratuitas@minvest-ferramentas
```

## Codex CLI

```sh
codex plugin marketplace add https://github.com/leonardomaia253/ferramentas.git --sparse .agents/plugins
codex plugin marketplace list
```

Install **MInvest Ferramentas Gratuitas** from the Codex desktop Plugins Directory. The public marketplace only includes the free tools plugin; it does not expose the private MInvest platform repository.

The free MCP tools are also available directly at:

`https://azobnryexzyeqbgtowyc.supabase.co/functions/v1/minvest-free-tools`

Market research requires explicit consent before topic, geography, audience, or decision context is sent to OpenAI. Do not submit personal data, private documents, secrets, or confidential business information. Calculations are educational estimates, not financial advice.
